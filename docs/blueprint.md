# **App Name**: AdFiHub

## Core Features:

- Marketplace Listings: Display and filter service listings with trust metrics and dispute options.
- User Authentication: Secure user sign-in via email/password and Web3 wallet connection.
- CPA/RevShare Estimator: AI-powered tool to estimate payouts and ROI for traffic strategies, providing plain-English recommendations and downloadable CSV simulations. The tool should estimate the conversion rate and incorporate it into its calculations
- Campaign Bundle Generator: Generative AI tool that creates ready-to-deploy ad campaign bundles, including ad copy, creative suggestions, landing page templates, and tracking parameters.
- Admin Moderation: Admin interface for managing users, listings, partners, and whitelist applications.
- Partner Directory: Categorized directory of partners with logos, blurbs, and integration statuses.
- Trust Badges & Compliance: Display trust badges and compliance information (Target Mafia, Consensus Capital, UK registration link).

## Style Guidelines:

- Primary color: Saturated blue (#29ABE2) for a sense of trust and technology.
- Background color: Light blue (#E5F5FF) for a clean and trustworthy backdrop.
- Accent color: Vibrant orange (#FF9933) for CTAs and important alerts, providing a contrasting but friendly tone.
- Headline font: 'Space Grotesk' (sans-serif) for a modern and technical look.
- Body font: 'Inter' (sans-serif) for clear readability and a neutral feel.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use simple, geometric icons to represent marketplace categories and features.
- Clean, grid-based layout with clear sections for listings, partner information, and AI tools.
- Subtle transitions and animations to enhance user experience without being distracting.
